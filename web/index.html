Operating Systems Laboratory Project Specification

DevGovernor is a lightweight, user-space developer productivity and scheduling-priority management prototype built for Linux operating systems.

1. The Linux /proc Virtual Filesystem

In Linux, /proc does not reside on any physical disk; it is an in-memory virtual filesystem generated on the fly by the Linux kernel. DevGovernor opens /proc/[pid]/status for process metadata (Name, State, PPID, VmRSS) and /proc/[pid]/stat for cumulative CPU clock ticks.

2. Two-Point CPU Utilization Sampling

Because the Linux kernel does not provide an instantaneous CPU percentage, DevGovernor performs two-point delta sampling across wall-clock time Δt:

CPU % = [(Δutime + Δstime) / CLK_TCK] / Δt * 100.0

3. Completely Fair Scheduler (CFS) & Nice Values

The Linux Completely Fair Scheduler uses nice values (-20 to 19) to scale each process's virtual runtime (vruntime) accumulation. Higher priority tasks (lower nice values) have higher weights in the kernel's sched_prio_to_weight array, allowing them to receive more CPU timeslices without starvation.

4. Physical RAM (VmRSS) vs. Virtual Memory (VmSize)

VmRSS (Resident Set Size): The actual physical frames in RAM currently held by the process. DevGovernor reports this value because it reflects true memory pressure.
VmSize (Virtual Size): The total virtual address space mapped (including uncommitted memory and shared libraries).

5. Atomic Inter-Process Communication (IPC)

Module 1 (C Monitor) writes its snapshot to data/processes.json.tmp and uses the POSIX rename() system call to atomically replace data/processes.json. This guarantees zero-race condition reads for the Python dashboard and Web UI.
